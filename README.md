# NovaSpace — 3D Space Explorer 🚀

A modern interactive space-themed website built with **HTML, CSS and JavaScript**.

## ✨ Features
- Interactive 3D-style planet
- Drag the planet with your mouse/finger
- Switch between different planets
- Animated star background
- Responsive design for mobile and desktop
- Smooth scrolling and micro-interactions
- No framework required

## 🛠️ Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API

## ▶️ Run locally
Just open `index.html` in your browser.
